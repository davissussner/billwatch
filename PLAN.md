# Congress bill summerizer

The end goal of this project is to summerize the most relevent 100 bills each month in congress, they need to fully emplain the bill and present an unbiased summary. It needs to be key word searchable and have the ability to sort the bills into several catagories.


A user might go into the system to search for bills related to the environment from July of 2026, or any other large catagory
